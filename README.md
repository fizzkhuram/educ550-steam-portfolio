# EDUC 550 – Grade 7 STEAM Portfolio

A responsive, image-rich academic portfolio website for GitHub Pages.

## Files
- `index.html` – complete portfolio content and structure
- `style.css` – responsive visual design
- `script.js` – navigation, active section tracking and image lightboxes
- `assets/` – original images extracted from the supplied final Word portfolio

## Publish on GitHub Pages
1. Download and extract this project ZIP.
2. Open your repository: `https://github.com/fizzkhuram/educ550-steam-portfolio`.
3. Upload/replace `index.html`, `style.css`, `script.js`, `README.md` and the complete `assets` folder in the repository root.
4. Commit the changes to the `main` branch.
5. In **Settings → Pages**, confirm **Deploy from a branch**, `main`, and `/(root)`.
6. After deployment, visit `https://fizzkhuram.github.io/educ550-steam-portfolio/`.

Keep the `assets` folder beside `index.html`; the page uses relative image paths.
